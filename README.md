# Starbound 百科 · 物品 / 配方 / 星球矿产

Starbound（星界边境）1.4.4 的**离线网页图鉴**，支持中文 / 拼音搜索，收录**本体 + 12 个模组**（Frackin' Universe、K'Rakoth、Voided、Arcana、王国守卫附属、酿造学等）的全部物品、配方、获取途径，每种星球能挖到什么矿、能收集到什么液体，以及全体船员的角色加成。

👉 打开 [`index.html`](index.html)（数据在 `data/`，整个仓库拷走即可离线使用）　·　在线版 <https://po1ardayyuzhou-hash.github.io/StarBoundCrafting/>

## 功能

- **搜索**：中文名 / 全拼 / 首字母 / 英文 ID 都能搜（`铁锭`、`tiekuang`、`tk`、`ironbar`），空格分隔多关键词，命中高亮
- **物品与配方**：19790 种物品、17234 条配方，卡片 / 表格双视图；材料、矿物、产物都能点开，有配方看合成表，没配方看获取途径（掉落 / 商人 / 宝箱 / 任务 / 挖矿）
- **星球百科**：127 种星球类型，列出威胁等级 1–10、推荐防护、矿产（分星球地表地下核心与轨道小行星，按等级解锁，每个矿标出该等级下的生成权重）、天气（持续时间 / 落体伤害 / 风力 / 附加状态）、地心形态（液态 / 实心，以及核心底部是什么液体、主体是什么岩层）、群系（分「星球内」与「太空」两类，组内按地表→地心 / 小行星带→大气层的层序排列并全部展开，每个群系列出该地形生成的主体方块与夹杂方块，带物品图标、点击可查合成配方，矿石另列），以及液体收集与空气冷凝在该星球能产出什么
- **酿造学**：效果材料 / 修饰材料按「第几次搅拌」列出 5 个槽位，某一次不产出就明确标「无效果」；另有状态效果时长表（5 级 × 4 形态）与 12 种特有药水的投料顺序
- **商人图鉴**：57 个商人、2235 条商品，可按本体 / 模组筛选、按商品名反查，档案给出商品池、出现地点与买入卖出系数
- **船员**：109 组船员的飞船属性加成、对话触发的临时状态与战斗数值，附「船员随护甲缩放」的成长说明；每张卡标注**获取途径**（空间站军事站价格 / 「合同：XXX」契约物品 / 招募方式），游戏内显示名可直接搜到（如「战争贩子」「大力神」）
- **防护背包 / EPP 模块**：228 件防护背囊与插件，效果带具体数值（免疫 / 抗性 / 防护 / 属性四类配色），点效果标签弹出说明
- **怪物图鉴**：1171 种怪物，按类别 / 所属模组筛选
- **状态效果**：1096 种玩家可见的 Buff / Debuff（本体 + 各模组），带游戏内图标、持续时间与来源，并给出**具体数值**（每秒扣血、移动 / 跳跃倍率、抗性与加成等，从效果配置和脚本里读出）；取不到数值的改用一句**作用说明**（如「持续回复生命值」「严寒环境：持续掉血并减速」），共 522 条有数值、其余都用一句话说明作用。名称、效果说明、数值 / 作用分三行显示——「酒醉[移动速度降低5%]」这类会拆成名称 + 说明，本身没有名字、整句都是描述的照原样显示。可按「异常 / 增益 / 其他」筛选、按名称或 ID 搜；游戏文件没有增益标记，分类按标签文字与效果字段推断
- **FU 生产**：筛粉（44 种）/ 粉碎（83 种）/ 离心机（78 种 × 木制·铁制·工业·实验室四台）/ 气体离心机（89 种）/ 萃取（1061 条配方）/ 冶炼（电弧炉、高炉、电炉三套表），投入与产物都可搜；**多产物带实际概率**——筛粉按「稀有度分档 → 档内 1/权重」折算，冶炼副产物按「总概率 × 各自权重」折算，并标出无产出概率
- **轨道目标**：27 类空间站、飞船与遗迹，带游戏内图标，可按类型筛选
- **筛选与体验**：制作站 / 分类 / 稀有度 / 来源 / 获取方式五组多选，条件写入地址栏可分享；深浅主题、`/` 聚焦搜索、手机适配

## 说明

- 页面本身 148 KB，数据拆为 5 个文件：物品与配方先行渲染，图标（6.9 MB）与星球数据并行加载后就地替换占位，首屏只需等 5.3 MB，回访命中缓存
- 静态快照，对应生成时的游戏版本与 Mod 列表；未收录任务奖励等动态内容。商人页列出的是商品池全集，游戏内每次刷新只随机抽取其中一部分
- `category`、`rarity` 等枚举值刻意不翻译，以免破坏筛选逻辑

## 配套：汉化补译 mod

> **⚠️ 使用前请先读这段**
>
> 这个补译 mod 的文本**由 AI 生成**，并且启动时要把近 6000 个补丁叠加到游戏资源上，**会让游戏启动时间增加 1–2 分钟**（只影响启动，进游戏后与原来一致）。
>
> **介意请勿使用。**

补译 Arcana / Voyage / 泰坦重工 / FU 等模组中官方汉化未覆盖的内容（名称、描述、任务、法典、导航台、船员对话），共 **5928 个 `.patch` + 99 个界面 `lua`、约 1.44 万条文本**，其中 1333 条长文本按英文原文逐条重写。除物品与书籍文本外，**界面文本**也做了补译：物质操纵器升级、科技树说明、飞船 GPS 面板、全息路由器、空间站、蜂箱、画板工具、传送门名称等——其中界面脚本（`.lua`）硬编码的文本无法用补丁修改，采用整文件替换，共 99 个文件。其中 `interface/cockpit/zzz_cockpit.lua`（导航控制台）基于原版脚本，**取消了“点空白处缩小”**：鼠标移到星图边缘不再变成放大镜，左键点空白也不会把视图缩小一层（原来会误把边缘星球当成空白区，导致某些星球点不到），缩小只用左下角的放大镜按钮；同时把星系视图的最小缩放从 `0.3` 降到 `0.12`，轨道半径很大的星系也能整屏显示，最外侧的星球不会被裁到窗口外。本次还补译了 45 个界面脚本里写死的英文：力场发生器/力场控制台的状态提示、强化插件提取器的物品名、SAIL 船员界面按钮、metagui 设置页（界面主题、滚动模式）、水井水位播报、地形改造器报错、飞船船员舱管理等。

另外 **More Planet Info** 的座舱星球面板也已汉化：星球类型、地表群系、昼长、环绕天体、气候威胁、地表分析等标签，加上 87 条地表物体扫描描述（各族地牢、遗迹、坠毁飞船）。该面板的座舱脚本以这个 mod 自带的版本为底稿重做，汉化与它新增的功能可以同时生效。

分两个包，按需取用，都**整个文件**放进 `Starbound/mods/`，不需要解压；`zzz_` 前缀确保最后加载：

| 文件 | 内容 | 说明 |
|---|---|---|
| [`TranslationSupplement_Lua.pak`](TranslationSupplement_Lua.pak) | 99 个界面脚本 | 体积 1 MB，启动几乎无额外耗时 |
| [`TranslationSupplement_Patch.pak`](TranslationSupplement_Patch.pak) | 5928 个文本补丁 | 会让启动多花 1–2 分钟 |

两个包互不重叠，可以只装前者、也可以都装。不要同时保留同名的目录，否则会加载两遍。

> 拆成两个包后，只装 `Lua` 包时启动开销几乎为零（99 个文件）；装 `Patch` 包才会多花 1–2 分钟。首次启动还需等资产库重建（黑屏、Steam 显示「运行中」属正常，**不要重复点击启动**）。

（`Lua` 包单独使用时，导航台的「取消点空白缩小 / 星系视图缩放」修正不会生效——那两处依赖 `Patch` 包里的配置补丁。）
