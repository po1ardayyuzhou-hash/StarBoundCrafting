# Starbound 合成表 · 中文搜索

Starbound（星界边境）1.4.4 全量合成表，**单文件网页**，支持中文 / 拼音搜索，包含**本体 + 已安装模组**（Frackin' Universe 等）的全部配方与物品，并标注每件物品的获取途径。

👉 打开 [`index.html`](index.html) 即可使用（无需联网、无需安装任何东西）。

> 若仓库已开启 GitHub Pages，可直接访问：<https://po1ardayyuzhou-hash.github.io/StarBoundCrafting/>

## 功能

**搜索**
- 中文名：`铁锭`、`胡萝卜`
- 全拼：`tiekuang`、`huluobo`
- 首字母：`tk`、`hlb`
- 英文 ID：`ironbar`
- 空格分隔多关键词（AND），同时匹配材料名与制作台名，命中处实时高亮

**浏览**
- **配方模式**：按产出物品浏览，卡片直接列出所需材料
- **物品模式**：按物品浏览，带「可合成 / 采集 / 怪物掉落 / 战利品 / 挖矿」徽章
- 卡片、表格双视图；120 条一页渐进加载

**筛选**
- 制作站 / 分类 / 来源 / 获取方式四组筛选，均为多选下拉（内置搜索、全选、计数）
- 已选条件以 chip 展示，可单独移除或一键清除
- 筛选状态写入地址栏，可直接收藏、分享某个筛选结果

**详情抽屉**
- 点击任意物品（包括卡片里的材料芯片）打开
- **获取途径**：合成配方、可采集植株、怪物掉落、宝箱战利品池、矿物分布
- **合成配方**：制作站 + 材料清单 + 配方文件路径
- **用于制作**：这件物品被哪些配方需要，可继续跳转

**FU 机器加工**
- 萃取设备（物质萃取器 / MKII / 手摇磨 / 量子萃取器）、筛粉机、碎岩机、离心机（铁制 / 工业 / 实验室）、气体离心机、木制离心机、先驱熔炉、异星实验室、液体混合器、蜂蜜灌装机、解剖台、灵能增幅器
- 这类配方按「输入 → 产出」逐条展开，标注**数量区间**（如 ×2-4）、**掉落概率**（常见 / 少见 / 稀有 / 极稀有），确定性多产物会列「同时产出」

**其他**
- 深 / 浅色主题（跟随系统，可手动切换并记忆）
- `/` 聚焦搜索，`Esc` 关闭
- 响应式，手机可用

## 获取途径是怎么来的

全部由游戏资源直接解析，不是手写整理的：

| 类型 | 数据来源 |
|---|---|
| 合成 | `recipes/*.recipe` |
| 采集 | 可采集对象的 `harvestPool` → `treasurepools` |
| 怪物掉落 | `monstertype` 的 `dropPools` |
| 战利品 / 宝箱 | `treasurepools` 池定义 |
| 挖矿 | `biomes/oredistributions.configfunctions` 判定地表 / 地下 |
| 机器加工 | FU 的 `extractionlab_recipes.config`、`centrifuge_recipes.config`、`xenostation_recipes.config`、`fu_liquidmixer_recipes.config` 等 7 份加工产出表 |

18208 件物品中有 7251 件没有任何静态来源（多为 FU 数据库里的装饰物、方块变体，或依赖养殖、任务、交易等动态机制的物品），其余均标注了至少一种获取方式。

## 配套：汉化补译 mod（FullTranslateCN）

针对 Arcana / Voyage / 泰坦重工 / FU 等模组中汉化补丁未覆盖的条目（名称、物品检视描述、任务面板文本、法典正文、NPC 对话、界面文字），生成了一个独立的 Starbound 补丁模组，直接放进游戏 `mods/` 目录即可生效（游戏内显示中文名称与描述，与合成表数据完全一致）。

| 项目 | 数量 |
|---|---|
| 名称补丁 | **4782 条**（物品、家具、科技、飞船、群系名） |
| 描述补丁 | **6214 条**（含七种族检视描述 `apexDescription` / `floranDescription` 等） |
| 任务面板文本 | **1503 条**（任务正文、目标、交任务说明、完成 / 失败文本） |
| 界面 / 状态文字 | **875 条**（UI 标签、无线电消息、状态效果） |
| 法典正文 | **112 条**（`contentPages` / `longContentPages` 长文） |
| 对话文本 | `/dialog/*.config` 的 NPC 问候与闲聊 |
| 覆盖资源文件 | 5862 个，合计 **13910 条文本字段** |
| 覆盖模组 | Arcana 奥法秘境、Voyage、泰坦重工拓展、Frackin' Universe、Galactic Almanach、Enhanced Storage 等 |

**安装**：把 `zzz_FullTranslateCN` 文件夹复制到 `Starbound/mods/` 下，重启游戏即可。mod 名带 `zzz_` 前缀，确保补丁在其他汉化之后加载、优先级最高。

**翻译说明**：专有名词先按统一术语表替换（如 Ariostone → 奥里石、Titancorp → 泰坦重工、Verrostin → 维罗斯廷），再交由 DeepL 翻译，确保名称与描述用词一致。属检索向译文，非官方译名。

**已知限制**：Starbound 的加载顺序是 本体 → `mods/` → 创意工坊，补丁按来源顺序叠加。少数由其它 mod「后期追加」的字段（如 Arcana 的星球类型描述、部分 mod 新增的对话种族）在本 mod 应用时还不存在，无法覆盖，仍需显示英文；此外 `category`、`rarity`、内部 id 等枚举值刻意不翻译，以免破坏配方与筛选逻辑。
