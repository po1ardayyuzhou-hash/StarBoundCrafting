# Starbound 百科 · 物品 / 配方 / 星球矿产

Starbound（星界边境）1.4.4 的**离线网页图鉴**，支持中文 / 拼音搜索，收录**本体 + 19 个模组**（Frackin' Universe 等）的全部物品、配方、获取途径，以及每种星球能挖到什么矿。

👉 打开 [`index.html`](index.html)（数据在 `data/`，整个仓库拷走即可离线使用）　·　在线版 <https://po1ardayyuzhou-hash.github.io/StarBoundCrafting/>

## 功能

- **搜索**：中文名 / 全拼 / 首字母 / 英文 ID（`铁锭`、`tiekuang`、`tk`、`ironbar`），空格分隔多关键词，材料名与制作台名同时匹配，命中高亮
- **浏览**：配方模式与物品模式双视图，卡片 / 表格切换，120 条渐进加载；7035 件既不可合成也无获取途径的物品单独归类，默认隐藏
- **星球百科**：档案含推荐防护（EPP）、矿产、地心类型、天气。矿产分**星球**（地表 / 地下 / 核心）与**轨道**（太空小行星）两组，带图标、按稀有度着色，点任意矿物即可跳到它的配方；多等级类型（如荒芜 1–6 级）可按等级切换矿表。天气不只列名称与占比，还标注持续时间、落体伤害、风力、雷电、附加状态与危险度（低 / 中 / 高）
- **商人图鉴**：**56** 个商人与 **2227** 条商品，可按本体 / 模组筛选、按商品名反查；档案列出该商人可能出售的全部物品（可跳转配方）、买入 / 卖出系数与商品池来源
- **怪物图鉴**：默认只列星球常驻的 292 种，另有 723 种任务 / 地牢专用；档案显示生命值、掉落、生成星球，均可跳转
- **筛选与详情**：制作站 / 分类 / 稀有度 / 来源 / 获取方式五组多选，条件写入地址栏可分享；物品抽屉显示获取途径、配方、用于制作
- **FU 特化**：机器加工按「输入 → 产出」展开并标注概率；蜂房 35 个蜂种共 451 条产出
- 深浅主题、`/` 聚焦搜索、响应式手机适配

## 数据来源

全部由游戏资源解析，非手工整理：合成 `recipes/*.recipe`；采集 `harvestPool` → `treasurepools`；掉落 `dropPools`；宝箱 `treasurepools`；挖矿 `oredistributions.configfunctions`；矿物产地 `.biome` 的 `ores` 键 + FU 矿脉补丁；商人商品 `/npcs/merchantpools.config` + `.npctype` 的 `scriptConfig.merchant`；机器加工 FU 的 7 份产出表；研究点数 `extractor_research.lua`（价格 × 稀有度 × 5%）。

18208 件物品中 7251 件没有任何静态来源（模组装饰物、方块变体，或依赖养殖 / 任务 / 交易等动态机制），其余至少标注一种。

## 说明

- 页面本身 75 KB，数据拆为 4 个文件：物品与配方先行渲染，图标（6.5 MB）与星球数据并行加载后就地替换占位，首屏只需等 5 MB，回访命中缓存
- 静态快照，对应生成时的游戏版本与 Mod 列表；未收录任务奖励等动态内容。商人页列出的是商品池全集，游戏内每次刷新只随机抽取其中一部分
- `category`、`rarity` 等枚举值刻意不翻译，以免破坏筛选逻辑
