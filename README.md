# Starbound 百科 · 物品 / 配方 / 星球矿产

Starbound（星界边境）1.4.4 的**单文件网页图鉴**，支持中文 / 拼音搜索，包含**本体 + 已安装模组**（Frackin' Universe 等）的全部物品与配方、每件物品的获取途径，以及**每种星球类型能挖到什么矿**。

👉 打开 [`index.html`](index.html) 即可使用（无需联网、无需安装任何东西）。

> 若仓库已开启 GitHub Pages，可直接访问：<https://po1ardayyuzhou-hash.github.io/StarBoundCrafting/>

## 功能

**搜索**
- 中文名：`铁锭`、`胡萝卜`
- 全拼：`tiekuang`、`huluobo`
- 首字母：`tk`、`hlb`
- 英文 ID：`ironbar`
- 空格分隔多关键词（AND），同时匹配材料名与制作台名，命中处实时高亮

**浏览**
- **配方模式**：按产出物品浏览，卡片直接列出所需材料
- **物品模式**：按物品浏览，带「可合成 / 采集 / 怪物掉落 / 战利品 / 挖矿」徽章
- 卡片、表格双视图；120 条一页渐进加载
- **无配方数据物品单独成类**：既不可合成、也无任何获取途径的 7035 件（多为模组残留与背景墙变体）默认不出现在物品列表里，避免淹没正常物品；需要时在「分类 → 无配方数据」中单独查看，搜索时仍可命中
- **稀有度可视化**：图标方框（内圈原色 + 外圈深色描边）与卡片左侧束带按稀有度着色 —— 普通灰 / 罕见绿 / 稀有蓝 / 传说紫 / 必需橙，传说与必需额外带光晕，扫一眼就能分辨品质

**星球百科**
- 119 种星球类型，卡片带**游戏内导航台图标**（114 种有官方素材，其余用威胁等级色球兜底）
- 可按「本体 / 模组」来源与威胁等级（1–6 级+）筛选；搜索框可搜星球名、矿物名、群系名
- 点击卡片展开档案，含四块内容：
  - **推荐防护**：灾种（酷热 / 严寒 / 辐射 / 真空…）与对应的 EPP 需求
  - **矿产**：合并地表、浅层、地下、核心层后去重，按矿物稀有度着色
  - **地心**：该星球核心层的类型（热核 / 橄榄岩核 / 酸性岩核…）
  - **天气**：非晴朗天气的候选列表
- 矿产按星球等级过滤 —— 1 级星球不会冒出日耀石这种高级矿

**怪物图鉴**
- **1015 种**怪物，按 30+ 个类别分组（步行 / 飞行 / 多节 / 虫类 / 头目 / 鱼类 / 幽灵…）
- 默认只列星球上能遇到的 **292 种**，另有 **723 种**任务、地牢、事件专用单位单列一档
- 档案显示：**生命值**、**掉落物品**（带背包图标，可跳转物品详情）、**生成星球**（可跳转星球档案）
- 掉落从 `monstertype` 的 `dropPools` 递归展开，含嵌套引用池

**筛选**
- 制作站 / 分类 / **稀有度** / 来源 / 获取方式五组筛选，均为多选下拉（内置搜索、全选、计数）
- 稀有度筛选带色点：普通灰 / 罕见绿 / 稀有蓝 / 传说紫 / 必需橙，另有「无标注」一档收纳模组未声明稀有度的物品
- 已选条件以 chip 展示，可单独移除或一键清除
- 筛选状态写入地址栏，可直接收藏、分享某个筛选结果

**详情抽屉**
- 点击任意物品（包括卡片里的材料芯片）打开
- **获取途径**：合成配方、可采集植株、怪物掉落、宝箱战利品池、矿物分布
- **合成配方**：制作站 + 材料清单 + 配方文件路径
- **用于制作**：这件物品被哪些配方需要，可继续跳转

**FU 机器加工**
- 萃取设备（物质萃取器 / MKII / 手摇磨 / 量子萃取器）、筛粉机、碎岩机、离心机（铁制 / 工业 / 实验室）、气体离心机、木制离心机、先驱熔炉、异星实验室、液体混合器、蜂蜜灌装机、解剖台、灵能增幅器
- 这类配方按「输入 → 产出」逐条展开，标注**数量区间**（如 ×2-4）、**掉落概率**（常见 / 少见 / 稀有 / 极稀有），确定性多产物会列「同时产出」

**FU 养蜂**
- 蜂房（Apiary / 大型蜂房 / 芳香蜂箱）的产出：35 个蜂种 × 基础/进阶两套产量表，共 451 条
- 每个蜂种还有一条繁育配方：蜂后 + 工蜂 → 幼年蜂后
- 产出表标注「需求」与「基础产量」两个原始参数（需求越小出得越快）

**其他**
- 深 / 浅色主题（跟随系统，可手动切换并记忆）
- `/` 聚焦搜索，`Esc` 关闭
- 响应式，手机可用

## 获取途径是怎么来的

全部由游戏资源直接解析，不是手写整理的：

| 类型 | 数据来源 |
|---|---|
| 合成 | `recipes/*.recipe` |
| 采集 | 可采集对象的 `harvestPool` → `treasurepools` |
| 怪物掉落 | `monstertype` 的 `dropPools` |
| 战利品 / 宝箱 | `treasurepools` 池定义 |
| 挖矿 | `biomes/oredistributions.configfunctions` 判定地表 / 地下；
| 矿物产地 | 每个矿物的「层 × 星球等级 × 群系」分布（`.biome` 的 `ores` 键 + FU 的 133KB 矿脉补丁），75 种矿物 |
| 机器加工 | FU 的 `extractionlab_recipes.config`、`centrifuge_recipes.config`、`xenostation_recipes.config`、`fu_liquidmixer_recipes.config` 等 7 份加工产出表 |
| 计算研究 | `/objects/generic/extractor_research.lua`：按「价格 × 稀有度 × 5%」折算，16461 件物品标注了研究点数 |

物品详情面板还会显示「计算机研究」一栏：投入 1 个（或若干个低价值物品）能在科研计算机上换到多少研究点数。

18208 件物品中有 7251 件没有任何静态来源（多为 FU 数据库里的装饰物、方块变体，或依赖养殖、任务、交易等动态机制的物品），其余均标注了至少一种获取方式。

## 配套：汉化补译 mod（TranslationSupplement）

针对 Arcana / Voyage / 泰坦重工 / FU 等模组中汉化补丁未覆盖的条目（名称、物品检视描述、任务面板文本、法典正文、NPC 对话、界面文字、**飞船导航台**），生成了一个独立的 Starbound 补丁模组，直接放进游戏 `mods/` 目录即可生效（游戏内显示中文名称与描述，与合成表数据完全一致）。

| 项目 | 数量 |
|---|---|
| 名称补丁 | **4782 条**（物品、家具、科技、飞船、群系名） |
| 描述补丁 | **6214 条**（含七种族检视描述 `apexDescription` / `floranDescription` 等） |
| 任务面板文本 | **1503 条**（任务正文、目标、交任务说明、完成 / 失败文本） |
| 界面 / 状态文字 | **875 条**（UI 标签、无线电消息、状态效果） |
| 法典正文 | **112 条**（`contentPages` / `longContentPages` 长文） |
| 对话文本 | `/dialog/*.config` 的 NPC 问候与闲聊 |
| 导航台（驾驶舱） | **344 条**：星球类型名 77、恒星名 12、威胁等级 10 档、星球描述 242 条、矿名 38、天气名 85、界面文字 37 |
| 覆盖资源文件 | 5862 个，合计 **约 1.43 万条文本字段** |
| 覆盖模组 | Arcana 奥法秘境、Voyage、泰坦重工拓展、Frackin' Universe、Galactic Almanach、Enhanced Storage 等 |

其中 **1333 条长文本**（任务正文与目标、法典与过场、物品描述）已按英文原文**逐条重写**，不再是机翻：修正了语序错位、颜色代码包错的词、`Bring X back to Y at Z` 之类的硬译，以及 `Alt`（按键）被译成「阿尔特」、`Credits` 被译成「拨款」这类误译。其余短条目沿用术语词典 + 机器翻译，并统一了标点与专名。

**导航台汉化**：飞船驾驶舱的星球信息面板已完整译成中文 —— 星球类型（繁茂 / 森林 / 焦土 / 阿特洛波斯 / 气态巨行星…）、恒星类型、威胁等级（无害（I）→ 免谈（X））、每种星球的三段随机描述、矿脉与天气名，以及「导航控制台 / 选择目的地 / 地质分析 / 添加书签」等界面文字。星球描述保留了原文的颜色标记，术语与游戏内物品名一致（如 `erchius` 统一译作「厄尔吉斯晶态燃料」）。

**安装**：把 `zzz_TranslationSupplement` 文件夹复制到 `Starbound/mods/` 下，重启游戏即可。mod 名带 `zzz_` 前缀，确保补丁在其他汉化之后加载、优先级最高。

**⚠️ 启动会明显变慢，这是正常现象**：本 mod 是 5862 个 `.patch` 文件，游戏每次启动都要逐个读取、解析，再套用到对应资源上。装上之后**冷启动的资源加载会从几十秒拉长到 60~90 秒**（实测 69~72 秒），这段时间：

- 游戏窗口迟迟不出现，屏幕是黑屏或桌面不动；
- Steam 好友列表显示「运行中」，但任务管理器里 `starbound.exe` 已经在吃 CPU；
- 这不是卡死，也不需要重装。

几条建议：

1. **耐心等**，不要在等待期间重复点击启动——多开实例只会更慢，甚至互相抢资源导致启动失败（日志会停在 `Loading assets from ...` 然后进程直接消失）。
2. 第二次进游戏会快一些，因为资源文件已被系统缓存。
3. 同时装了多个大型内容 mod（FU、Arcana 等）时，加载时间会更长，本 mod 只是其中一部分。
4. 如果超过 3 分钟仍无窗口，先在任务管理器确认是不是开了多个 `starbound.exe`，结束多余的再重试。

想加快的话，可以在打完一局后**不要退出游戏**，直接从主菜单继续；或者接受这个开销——它是补丁式汉化的固有代价。

**翻译说明**：专有名词先按统一术语表替换（如 Ariostone → 奥里石、Titancorp → 泰坦重工、Verrostin → 维罗斯廷），再交由 DeepL 翻译，确保名称与描述用词一致。属检索向译文，非官方译名。

**已知限制**：Starbound 的加载顺序是 本体 → `mods/` → 创意工坊，补丁按来源顺序叠加。少数由其它 mod「后期追加」的字段（如 Arcana 的星球类型描述、部分 mod 新增的对话种族）在本 mod 应用时还不存在，无法覆盖，仍需显示英文；此外 `category`、`rarity`、内部 id 等枚举值刻意不翻译，以免破坏配方与筛选逻辑。
