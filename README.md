# Starbound 百科 · 物品 / 配方 / 星球矿产

Starbound（星界边境）1.4.4 的**离线网页图鉴**，支持中文 / 拼音搜索，收录**本体 + 11 个模组**（Frackin' Universe、K'Rakoth、Voided、Arcana、酿造学等）的全部物品、配方、获取途径，每种星球能挖到什么矿、能收集到什么液体，以及全体船员的角色加成。

👉 打开 [`index.html`](index.html)（数据在 `data/`，整个仓库拷走即可离线使用）　·　在线版 <https://po1ardayyuzhou-hash.github.io/StarBoundCrafting/>

## 功能

- **搜索**：中文名 / 全拼 / 首字母 / 英文 ID（`铁锭`、`tiekuang`、`tk`、`ironbar`），空格分隔多关键词，材料名与制作台名同时匹配，命中高亮
- **浏览**：配方模式与物品模式双视图，卡片 / 表格切换，120 条渐进加载；7905 件既不可合成也无获取途径的物品单独归类，默认隐藏
- **星球百科**：档案含推荐防护（EPP）、矿产、地心类型、天气、**威胁等级**（10 档「无害（I）…免谈（X）」档位彩签 + 说明，与游戏内导航台文案一致）。矿产分**星球**（地表 / 地下 / 核心）与**轨道**（太空小行星）两组，带图标、按稀有度着色，点任意矿物即可跳到它的配方；多等级类型（如荒芜 1–6 级）可按等级切换矿表。天气不只列名称与占比，还标注持续时间、落体伤害、风力、雷电、附加状态与危险度（低 / 中 / 高）
- **液体收集 / 空气冷凝**：星球档案列出**液体收集器**（31 种星球专属池）、**泰坦 MK2 冷凝器**（14 种）与**空气冷凝器**（23 种实体池，星球别名自动转发）在该星球能产出什么——产物随星球类型变化，不进合成表；空气冷凝器还标注常见 79% / 罕见 20% / 稀有 1% 三档抽取概率
- **酿造学（Brewology）独立页签**：酿造流程四步总览、四种药水形态（直饮/喷溅/扩散/喷雾）；效果材料 43 / 修饰 11 / 聚合剂 7 / 溶剂 10，带游戏内编号与效果等级；状态效果 39（5 级 × 4 形态持续时长）、修饰 10、**特有药水 12**（含可复现的投料顺序配方步骤与手稿原文）；文案取自模组自带简中补丁，游戏内 `^#RRGGBB;` 颜色标记原样还原
- **商人图鉴**：**57** 个商人与 **2235** 条商品，可按本体 / 模组筛选、按商品名反查；档案列出该商人可能出售的全部物品（可跳转配方）、**出现地点**（前哨站 / 殖民地房客 / 星球地牢 / 任务 / 太空目标，按资源引用反查）、买入 / 卖出系数与商品池来源
- **船员效果**：**98** 组船员角色（本体 12 / FU 56 / Arcana 30），列出飞船属性加成（速度 / 燃料效率 / 燃料上限，船员在船即生效、可叠加）、与船员对话触发的临时状态（带游戏内图标与持续时间）、船上常驻增益与生命恢复，以及**战斗数值简介**（生命 / 攻击倍率 / 回血 / 状态免疫，沿 `baseType` 继承链解析）；按来源筛选，可按名称 / 特长 / 效果 / 战斗属性搜索。化学家 A/B/C/D 等变体按 `baseType` 继承链解析出完整角色档案
- **船员成长机制**（折叠面板）：船员**没有等级、不能升级**，头顶军衔是招募时随机抽取的装饰文本；但战斗数值随玩家护甲实时缩放（生命 = 基础 + 护甲生命加成、防御 = 护甲防御值、回血固定 2/秒、攻击倍率 = 0.25 × 护甲倍率 ^ 成长指数），每 2 秒刷新；附护甲 0–6 级 + 操控者的攻击倍率对照表（25% → 529%）；每张卡片标注成长指数（标准 ×1.0，斧力士 ×1.5）
- **防护背包 / EPP 模块**：从合成表里独立成栏，**222** 件（防护背囊 85 / EPP 插件 137），按引擎 `category` 精确划分（混在中文分类里的 25 件背部时装已剔除）。卡片直接列出防护效果（免疫 / 抗性 / 防护 / 属性四类配色，如「辐射免疫」「宇宙射线抗性 25%」「供氧」），并标注可合成与否；**点效果标签弹出说明**（该效果的具体作用 + 有多少件物品带同款效果 + 示例物品名），点卡片其他位置打开抽屉：**有配方看合成表**（材料 + 制作台 + 逐条配方），**无配方看获取途径**（掉落 / 商人 / 宝箱 / 任务），效果小节始终在最前
- **轨道目标**：星系轨道上的空间站、飞船与遗迹共 **27** 类（36 个变体），**不能直接降落**，需驾驶机甲飞近后登舰；带游戏内图标，可按类型筛选、按名称或描述搜索。游戏里显示同一个名字的目标合并成一张卡，抽屉里逐个列出各变体的内部标识与独立描述
- **怪物图鉴**：默认只列星球常驻的 450 种，另有 720 种任务 / 地牢专用；档案显示生命值、掉落、生成星球，均可跳转
- **筛选与详情**：制作站 / 分类 / 稀有度 / 来源 / 获取方式五组多选，条件写入地址栏可分享；物品抽屉显示获取途径、配方、用于制作
- **FU 特化**：机器加工按「输入 → 产出」展开并标注概率；蜂房 35 个蜂种共 451 条产出；星球威胁等级与液体 / 空气冷凝产物取自 FU 的 cockpit 配置与冷凝产出表
- 深浅主题、`/` 聚焦搜索、响应式手机适配

## 数据来源

全部由游戏资源解析，非手工整理：合成 `recipes/*.recipe`；采集 `harvestPool` → `treasurepools`；掉落 `dropPools`；宝箱 `treasurepools`；挖矿 `oredistributions.configfunctions`；矿物产地 `.biome` 的 `ores` 键 + FU 矿脉补丁，方块名与物品 id 不一致时按 `.matmod` 的 `itemDrop` 对应（如 `fublooddiamond` → 血晶）；商人商品 `/npcs/merchantpools.config` + `.npctype` 的 `scriptConfig.merchant`；轨道目标 `/system_objects.config`；机器加工 FU 的 7 份产出表；液体收集 `fu_liquidcondenser` / 泰坦 MK2 / `isn_atmoscondenser` 的星球类型产出表；船员取自 `/npcs/crew/*.npctype` 的角色加成与 `/stats/effects/**` 的状态效果文案、图标（飞船属性基数见 `ships/shipupgrades.config`）；防护背包与 EPP 插件取自 `.back` / `.augment` 的 `statusEffects` 与 `augment.effects`（无 label 的效果按 id 自建中文名）；酿造学取自 uniquePotion 配置键名与手稿文本；研究点数 `extractor_research.lua`（价格 × 稀有度 × 5%）。

19715 件物品中 7924 件没有任何静态来源（模组装饰物、方块变体，或依赖养殖 / 任务 / 交易等动态机制），其余至少标注一种（合成 / 采集 / 掉落 / 宝箱 / 商人 / 挖矿）。

## 说明

- 页面本身 114 KB，数据拆为 4 个文件：物品与配方先行渲染，图标（6.9 MB）与星球数据并行加载后就地替换占位，首屏只需等 5.6 MB，回访命中缓存
- 静态快照，对应生成时的游戏版本与 Mod 列表；未收录任务奖励等动态内容。商人页列出的是商品池全集，游戏内每次刷新只随机抽取其中一部分
- `category`、`rarity` 等枚举值刻意不翻译，以免破坏筛选逻辑
