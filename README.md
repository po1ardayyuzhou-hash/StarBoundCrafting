# Starbound 百科 · 物品 / 配方 / 星球矿产

Starbound（星界边境）1.4.4 的**离线网页图鉴**，支持中文 / 拼音搜索，收录**本体 + 11 个模组**（Frackin' Universe、K'Rakoth、Voided、Arcana、酿造学等）的全部物品、配方、获取途径，每种星球能挖到什么矿、能收集到什么液体，以及全体船员的角色加成。

👉 打开 [`index.html`](index.html)（数据在 `data/`，整个仓库拷走即可离线使用）　·　在线版 <https://po1ardayyuzhou-hash.github.io/StarBoundCrafting/>

## 功能

- **搜索**：中文名 / 全拼 / 首字母 / 英文 ID 都能搜（`铁锭`、`tiekuang`、`tk`、`ironbar`），空格分隔多关键词，命中高亮
- **物品与配方**：19715 种物品、17153 条配方，卡片 / 表格双视图；材料、矿物、产物都能点开，有配方看合成表，没配方看获取途径（掉落 / 商人 / 宝箱 / 任务 / 挖矿）
- **星球百科**：127 种星球类型，列出威胁等级 1–10、推荐防护、矿产（分星球地表地下核心与轨道小行星，按等级解锁）、天气（持续时间 / 落体伤害 / 风力 / 附加状态）、地心类型，以及液体收集与空气冷凝在该星球能产出什么
- **酿造学**：效果材料 / 修饰材料按「第几次搅拌」列出 5 个槽位，某一次不产出就明确标「无效果」；另有状态效果时长表（5 级 × 4 形态）与 12 种特有药水的投料顺序
- **商人图鉴**：57 个商人、2235 条商品，可按本体 / 模组筛选、按商品名反查，档案给出商品池、出现地点与买入卖出系数
- **船员**：98 组船员的飞船属性加成、对话触发的临时状态与战斗数值，附「船员随护甲缩放」的成长说明；每张卡标注**获取途径**（空间站军事站价格 / 「合同：XXX」契约物品 / 招募方式），游戏内显示名可直接搜到（如「战争贩子」「大力神」）
- **防护背包 / EPP 模块**：222 件防护背囊与插件，效果带具体数值（免疫 / 抗性 / 防护 / 属性四类配色），点效果标签弹出说明
- **Boss 图鉴**：31 个交战时会占据屏幕底部血条的强敌，含血量、防御、接触伤害、攻击方式、典籍故事与掉落；1170 种怪物分星球常驻与任务专用
- **状态效果**：1066 种玩家可见的 Buff / Debuff（本体 + 各模组），带游戏内图标、持续时间与来源，并给出**具体数值**（每秒扣血、移动 / 跳跃倍率、抗性与加成等，从效果配置和脚本里读出）；取不到数值的改用一句**作用说明**（如「持续回复生命值」「严寒环境：持续掉血并减速」），共 549 条有数值、其余都用一句话说明作用。名称、效果说明、数值 / 作用分三行显示——「酒醉[移动速度降低5%]」这类会拆成名称 + 说明，本身没有名字、整句都是描述的照原样显示。可按「异常 / 增益 / 其他」筛选、按名称或 ID 搜；游戏文件没有增益标记，分类按标签文字与效果字段推断
- **轨道目标**：27 类空间站、飞船与遗迹，带游戏内图标，可按类型筛选
- **筛选与体验**：制作站 / 分类 / 稀有度 / 来源 / 获取方式五组多选，条件写入地址栏可分享；深浅主题、`/` 聚焦搜索、手机适配

## 说明

- 页面本身 148 KB，数据拆为 4 个文件：物品与配方先行渲染，图标（6.9 MB）与星球数据并行加载后就地替换占位，首屏只需等 5.3 MB，回访命中缓存
- 静态快照，对应生成时的游戏版本与 Mod 列表；未收录任务奖励等动态内容。商人页列出的是商品池全集，游戏内每次刷新只随机抽取其中一部分
- `category`、`rarity` 等枚举值刻意不翻译，以免破坏筛选逻辑
